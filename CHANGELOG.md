# Changelog

User-facing changes to VerifyVision.

## 1.0.0 — 2026-08-21

First stable local-only release.

- Added NVIDIA LocateAnything-3B annotation on supported CUDA systems.
- Added prompt-based classes, direct class editing, and saved model provenance.
- Added Accept, Adjust, Reject, and Human Added verification workflows.
- Added annotation undo/redo and image and box deletion.
- Added quality analytics by class, prompt, and correction type.
- Added YOLO, COCO, Pascal VOC, and Evaluation CSV exports.
- Added CUDA Ultralytics YOLO training with dataset reuse, progress, metrics, checkpoints, and cancellation.
- Added checkpoint testing with project images and separate uploads.
- Added hardware-aware LocateAnything FP16/BF16 selection and resident-model reuse.
- Added local setup checks and dependency update checks.
